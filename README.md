# 🧩 @vigihdev/assets-mini

> Super mini asset builder config (SASS + JS concat)

`@vigihdev/assets-mini` adalah package kecil yang menyediakan konfigurasi sederhana untuk membangun **asset front-end** seperti **SASS → CSS** dan **JavaScript concat** tanpa framework build besar seperti Webpack, Gulp, atau Vite.  
Cocok untuk project kecil, tema WordPress, atau plugin PHP.

---

## 🚀 Fitur

- 🔹 Kompilasi **SASS/SCSS → CSS**
- 🔹 Penggabungan file **JavaScript** menjadi satu file
- 🔹 Struktur direktori yang bersih dan fleksibel
- 🔹 Siap digunakan di CLI, Node.js, atau build script custom

---

## 📦 Instalasi

```bash
npm install @vigihdev/assets-mini --save-dev
```
